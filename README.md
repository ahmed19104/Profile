# Ahmed Yaser - Portfolio

A single-page, dark-themed **portfolio website** for Ahmed Yaser, Software Engineer and .NET Developer. It is bilingual (**English / Arabic**) with a language switch in the header.

## Sections

- **Hero:** name, title and short introduction, with links to GitHub and LinkedIn.
- **Core skills:** Clean Architecture, AI integration (Gemini), C# / .NET 8, ASP.NET MVC / Web API, Entity Framework / LINQ, SignalR / Hangfire, SQL Server (Code-First), JWT and security, system design.
- **Key projects:**
  - **Ather - Smart Tourism:** ASP.NET Core 8 with Clean Architecture, real-time messaging (SignalR), scheduled jobs (Hangfire) and an AI microservice (Gemini API and Python) for monument recognition.
  - **MoviesCLS - Cinema Management:** ASP.NET Core MVC ticket platform with Code-First migrations and many-to-many relationships.
- **Certifications and honors:** ITI Web Development (.NET), 120 hours (Aug - Oct 2025); Capital University academic achievement, 10th place in the 4th level (2025/2026).
- **Contact.**

## Tech stack

HTML5 and CSS3 (custom properties, grid, flexbox), vanilla JavaScript for the language switch, Google Fonts (Inter). No build step and no dependencies.

## Run it

Open `index.html` in a browser, or publish the repo with GitHub Pages.

```bash
git clone https://github.com/ahmed19104/Profile.git
cd Profile
# open index.html
```
